# Asas v0.2.0 Core Enhancements Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship Asas v0.2.0: return-annotation endpoints with correct caller signatures, `Annotated` parameter markers, typed errors, event hooks, client lifecycle, generic resources, and the listed correctness fixes.

**Architecture:** Each decorated method is compiled once into an `EndpointSpec` (`asas/endpoint.py`) that knows where every parameter goes and how to parse the response. A single pipeline (`execute_sync` / `execute_async` in `asas/decorators.py`) applies auth, hooks, the 401 retry, status-error mapping, and parsing; endpoints and resources both run through it. Engines stay transport adapters, now also honouring cookies/timeouts and wrapping transport errors.

**Tech Stack:** Python ≥3.10, pydantic v2 (`TypeAdapter`), httpx 0.24+, optional requests, pytest + pytest-asyncio (explicit marks) + respx, mypy strict.

**Spec:** `docs/superpowers/specs/2026-11-09-v0.2-core-enhancements-design.md` — read it alongside this plan; section numbers below (§N) refer to it.

## Global Constraints

- `requires-python = ">=3.10"`; code must run on 3.10 (no `typing.Self`, use `typing_extensions.Self`; no 3.11+ syntax/stdlib). The local venv is 3.11 — CI is the 3.10 check.
- Version `0.2.0`. Classifiers 3.10, 3.11, 3.12, 3.13. CI matrix `["3.10", "3.11", "3.12", "3.13"]`.
- `typing_extensions` is a declared dependency.
- mypy strict (`disallow_untyped_defs`) passes on `asas/` and `tests/typing_check.py`.
- Async tests use explicit `@pytest.mark.asyncio`; HTTP mocked with `respx` against `BASE = "https://api.example.com"`.
- Every new user-facing name is exported from `asas/__init__.py` and listed in `__all__` (§11).
- Commits use gitmoji prefixes and end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. Pre-commit hooks (isort, black, mypy) must pass; never `--no-verify`.
- Docs are bilingual: every `docs/*.md` change has a matching `docs/*.ar.md` change.
- `site/` is generated — never edit it.

## Review Focus

1. **Forward references** — a return or parameter type defined *after* the client class (or `from __future__ import annotations`) must work; expected: compile is retried on first call instead of failing at import. Test in Task 4.
2. **Wrong call arguments** — a missing required argument or an unknown keyword must raise Python's normal `TypeError`, not silently send a request. Test in Task 5.
3. **Non-UTF-8 / large error bodies** — an HTML or binary 502 body must produce a readable message truncated to 200 chars, never a decode crash. Test in Task 1.
4. **Optional return on error** — `-> User | None` receiving a 404 must raise `NotFoundError`, not return `None`. Test in Task 7.
5. **OpenAPI-style placeholder names** — `{userId}` bound to `user_id: Annotated[int, Path(alias="userId")]` must compile and substitute. Test in Task 4 (compile) and Task 5 (substitution).

### Task 4: EndpointSpec compilation

**Files:**
- Create: `asas/endpoint.py`
- Test: `tests/test_endpoint_compile.py`

**Interfaces:**
- Consumes: `asas.params` (Task 3).
- Produces:
  - `ReturnKind = Literal["response", "none", "bytes", "str", "model"]`
  - `@dataclass(frozen=True) class EndpointOptions`: `headers: Mapping[str, str] | None = None`, `timeout: float | None = None`, `use_auth: bool = True`, `raise_for_status: bool | None = None`, `hooks: "Hooks | None" = None` (forward ref; `Hooks` arrives in Task 7 — annotate as `Any` here and tighten in Task 7).
  - `@dataclass(frozen=True) class ParamSpec`: `name: str`, `location: Location`, `wire_name: str`, `annotation: Any`, `marker: Param`, `adapter: TypeAdapter[Any]`.
  - `class EndpointSpec`: attributes `method: str`, `path: str`, `is_async: bool`, `signature: inspect.Signature`, `params: tuple[ParamSpec, ...]`, `return_kind: ReturnKind`, `return_adapter: TypeAdapter[Any] | None`, `returns_optional: bool`, `options: EndpointOptions`.
  - `@classmethod EndpointSpec.compile(cls, method: str, path: str, func: Callable[..., Any], options: EndpointOptions) -> EndpointSpec` — raises `TypeError` for declaration errors; lets `NameError` from unresolved forward refs propagate (the decorator handles it in Task 7).
  - `@property EndpointSpec.effective_raise_for_status -> bool | None` — `False` when `return_kind == "response"`, else `options.raise_for_status`.

**Rules** (§5 inference and validation; §6 return kinds):
- Hints via `typing.get_type_hints(func, include_extras=True)`; skip `self`.
- Marker = the `Param` instance inside `Annotated[...]` metadata, else inferred: name in path placeholders → `Path`; base type (after stripping `Optional`/`None` from a union) is a `BaseModel` subclass, `list[BaseModel]`, or `dict`/`dict[...]` → `Body`; else `Query`.
- `wire_name`: `marker.alias` if set; for `Header` without alias: `"-".join(p.capitalize() for p in name.split("_"))`; else `name`.
- Placeholders: `re.findall(r"{([^{}]+)}", path)`; a `Path` param's `wire_name` must match a placeholder.
- Return kind: `Response` → `"response"`; `None`/`type(None)` → `"none"`; `bytes` → `"bytes"`; `str` → `"str"`; anything else → `"model"` with `TypeAdapter(annotation)`. `returns_optional` = `None` is a member of the return union.
- Adapter for `File` params is not needed — use `TypeAdapter(Any)`.

### Task 5: Request building and serialization

**Files:**
- Modify: `asas/endpoint.py`
- Test: `tests/test_params.py` (append)

**Interfaces:**
- Consumes: `EndpointSpec`, `ParamSpec` (Task 4); `Request`, `Payload` (Task 2).
- Produces:
  - `EndpointSpec.build_request(self, base_url: str, args: tuple[Any, ...], kwargs: dict[str, Any]) -> Request` — **no auth**. `args` excludes `self`.
  - `def dump_body(value: Any, adapter: TypeAdapter[Any] | None = None, *, exclude_unset: bool = False, exclude_none: bool = False) -> Any` — JSON-safe, `by_alias=True`; when `adapter` is `None` uses `TypeAdapter(type(value))`. Used by resources in Task 9.

**Rules** (§5 serialization, header precedence):
- Bind with `self.signature.bind(None, *args, **kwargs)` (strict `bind`, not `bind_partial`), then `apply_defaults()`.
- Non-body values: `adapter.dump_python(v, mode="json", by_alias=True)`, then booleans → `"true"`/`"false"`, other scalars → `str`; list/tuple in query → list of strings (repeated keys).
- `None` omitted from query/header/cookie/form; `None` path value → `ValueError` naming the param.
- Path values: `urllib.parse.quote(str_value, safe="")`.
- URL: `f"{base_url}/{path.lstrip('/')}"`.
- Body → `Payload(json=dump_body(...))`; form only → `Payload(data={...})`; any `File` → `Payload(data={form fields}, files={wire_name: value})`.
- Headers: `dict(options.headers or {})` then `Header()` params override.
- `Request.timeout = options.timeout`.
